# N.Elora — Bunga Kawat Bulu Handmade

Website landing page untuk **N.Elora**, toko bunga kawat bulu handmade. Dibuat dengan HTML, CSS, dan JavaScript (GSAP untuk animasi).

## Fitur

- Hero section dengan animasi GSAP
- Katalog produk (Buket, Bunga Tunggal, Custom)
- Filter produk
- Integrasi WhatsApp untuk pemesanan
- Floating WhatsApp button
- Responsif (mobile & desktop)
- Kelopak bunga jatuh (efek dekoratif)

## Struktur Folder

```
n-elora/
├── index.html
├── logo-nelora.png
├── README.md
└── .gitignore
```

## Cara Menjalankan

Buka `index.html` langsung di browser, atau jalankan server lokal:

```bash
npx serve .
```
